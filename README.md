# Missão LGPD

Jogo de pesquisa sobre a LGPD para o 2º ano (Suporte Técnico e Atendimento ao Usuário: segurança da informação e privacidade dos dados).

**Jogar:** https://fernandobalbino.github.io/missao-lgpd/

- 8 fases, uma pergunta por fase; a fase 8 é o "chefão" (LGPD no suporte técnico).
- Copiar e colar ficam bloqueados na caixa de resposta: o aluno precisa pesquisar e escrever.
- Mínimo de 80 caracteres por resposta (constante `MIN` no `index.html`).
- O progresso fica salvo no navegador do aluno. No final ele copia as respostas (para colar no Google Docs/Classroom) ou imprime em PDF.

Um único arquivo: `index.html` (HTML + CSS + JS, sem build). Para mudar perguntas, edite o array `FASES`.
